## Про проект

**Хаб Українізаторів BDO - WWM** — це Windows-хаб для встановлення та керування українськими локалізаціями ігор. Наразі функціонально інтегровано [Black Desert Online](https://www.blackdesertonline.com/); [Where Winds Meet](https://www.wherewindsmeetgame.com/) є наступною ціллю інтеграції, але ще не підтримується застосунком.

Застосунок працює з інтеграцією [BDO UA Translate](https://bdo-ua.com.ua/) для Black Desert Online та отримує актуальні релізи через публічний API. Інтеграція [Winds4UA (W4U)](https://winds4ua.com.ua/) для Where Winds Meet запланована; встановити її через Хаб поки неможливо, дати доступності немає.

### Цільові проєкти локалізації

| Гра | Проєкт | Статус |
|---|---|---|
| Black Desert Online | [BDO UA Translate](https://bdo-ua.com.ua/) | Доступно та інтегровано |
| Where Winds Meet | [Winds4UA (W4U)](https://winds4ua.com.ua/) | Інтеграція запланована |

Where Winds Meet / Winds4UA (W4U) ще не можна встановити через Хаб. Дата доступності не визначена; інтеграція залежить від окремого технічного контракту.

Проєкт є волонтерським та підтримується спільнотою.

### Можливості

- Автоматичний пошук встановленої гри
- Встановлення та оновлення локалізації з перевіркою SHA-256
- Кілька режимів локалізації на вибір
- Відновлення офіційного файлу гри
- Захист файлів гри: бекапи, атомарна заміна, rollback при помилках
- Детальні логи для діагностики
- Робота в системному треї
- Фонове відстеження оновлень
- Windows autostart і запуск у фоновому режимі
- Інформаційне сповіщення, коли доступне оновлення локалізації для встановлення

### Трей і фоновий режим

Звичайне натискання **X** ховає **Хаб Українізаторів BDO - WWM** у системний трей, не завершуючи програму. Меню іконки трея містить **"Відкрити"**, **"Перевірити зараз"**, **"Запускати разом із Windows"** і **"Вихід"**. Подвійний клік по іконці відновлює застосунок, а **"Вихід"** повністю завершує його.

За бажанням застосунок запускається разом із Windows у фоновому режимі. Коли вікно видиме, перевірки API виконуються частіше; у фоновому режимі — навмисно рідше, щоб заощаджувати ресурси. Прихований застосунок також може виявити важливу локальну зміну файлу локалізації. Хаб додатково перевіряє наявність новішої версії приблизно кожні 5 хвилин; якщо нову версію знайдено у прихованому режимі, Windows показує одне сповіщення для цієї версії. Після відкриття програми доступна звичайна кнопка оновлення. Пункт **"Перевірити зараз"** перевіряє і локалізаційний фід, і доступність нової версії застосунку. Сповіщення є інформаційним і не запускає оновлення автоматично; для відкриття використовуйте трей.

Фоновий режим розрахований на роботу без помітного навантаження на комп’ютер. На наведеному вимірюванні в Диспетчері завдань Хаб Українізаторів BDO - WWM споживає **0% CPU**, близько **17,6 МБ оперативної пам’яті**, а активність диска та мережі становить **0 Мбіт/с**. Фактичні показники можуть трохи відрізнятися залежно від системи та моменту перевірки, але застосунок виконує фоновий моніторинг ощадливо й не заважає повсякденній роботі.

![Хаб Українізаторів BDO - WWM у фоновому режимі — споживання ресурсів](docs/img/background-resource-usage.png)

## Завантаження

Офіційні збірки Хабу Українізаторів BDO - WWM публікуються на сторінці **[GitHub Releases](https://github.com/merelyigor/ua-localization-hub/releases)**.

Завантажте canonical ZIP-архів:

```
BDO-UA-Client-vX.Y.Z-win-x64.zip
```

Public release містить один GitHub-generated application ZIP. Усередині нього рівно чотири flat-файли: `BDO-UA-Client.exe`, `release-manifest.json`, `SHA256SUMS.txt` і release notes. Project-created nested ZIP не використовується.

Для роботи не потрібно встановлювати .NET Runtime — застосунок самодостатній (self-contained).

### Системні вимоги

- Windows 10/11 x64
- Підключення до інтернету
- Встановлена Black Desert Online

## Windows SmartScreen

Хаб Українізаторів BDO - WWM наразі не підписаний комерційним сертифікатом підпису коду (code-signing certificate). Тому Windows SmartScreen може показати попередження **"Невідомий видавець"** при першому запуску.

Наявність цього попередження сама по собі не означає, що файл є шкідливим. Windows може показувати SmartScreen для застосунків без впізнаваного цифрового підпису видавця або з недостатньою репутацією.

### Як запустити

1. Завантажте canonical ZIP тільки з офіційної сторінки [GitHub Releases](https://github.com/merelyigor/ua-localization-hub/releases) репозиторію `merelyigor/ua-localization-hub`.
2. Розпакуйте **BDO-UA-Client.exe**.
3. Запустіть **BDO-UA-Client.exe**.
4. Якщо з'явилось вікно SmartScreen, натисніть **"Докладніше"**.

![Windows SmartScreen — Докладніше](docs/img/smartscreen-more-info.png)

5. Перевірте, що вказано **BDO-UA-Client.exe**.
6. Натисніть **"Виконати"**.

![Windows SmartScreen — Виконати](docs/img/smartscreen-run-anyway.png)

> **Увага:** не натискайте "Виконати" для файлів, завантажених з невідомих сторонніх джерел. Використовуйте тільки офіційну сторінку релізів.

## Як видалити Хаб Українізаторів BDO - WWM

Хаб Українізаторів BDO - WWM — portable-застосунок: він не встановлюється у Windows через MSI/MSIX або Windows Installer, тому окремого деінсталятора у **Programs and Features** немає. Для сумісності поточний виконуваний файл зберігає технічну назву **`BDO-UA-Client.exe`**.

### Звичайне видалення

1. Якщо увімкнено автозапуск, спочатку вимкніть його в меню іконки трея **«Запускати разом із Windows»**.
2. Повністю завершіть застосунок через меню трея **«Вихід»**. Натискання **X** лише ховає програму у трей і не завершує процес.
3. Видаліть файл **`BDO-UA-Client.exe`**.

### Повне очищення даних

Окремо від EXE можуть залишатися технічні дані застосунку у `%LocalAppData%\BDO-UA-Client`: конфігурація, логи, стан встановлення, тимчасові файли cache, резервні копії та дані сесій оновлення. Цей шлях збережено для сумісності. Якщо ці дані більше не потрібні, після повного завершення застосунку можна видалити всю цю папку. Логи та резервні копії можна залишити, якщо вони потрібні для діагностики або відновлення.

Видалення застосунку або його папки даних **не відновлює і не видаляє локалізацію, вже застосовану до Black Desert Online**. Якщо потрібно повернути оригінальну локалізацію гри, перед видаленням застосунку використайте його дію **«Відновити оригінал»**. Якщо локалізацію потрібно залишити, цю дію виконувати не потрібно.

## Пошук гри

Після запуску застосунок автоматично шукає встановлену Black Desert Online. Якщо гра знайдена, відображається її статус; коли файл `ads_files` містить розпізнаваний патч локалізації, патч додається до статусу:

> ✓ Гру знайдено • patch 398

Якщо патч визначити неможливо, залишається звичайний статус **✓ Гру знайдено**.

Якщо гра не знайдена автоматично, скористайтеся кнопкою автоматичного пошуку або оберіть папку кнопкою **"Обрати папку"**. Коли гра вже знайдена, кнопка **"Перевірити"** запускає її повторну перевірку.

### Ручний вибір папки

Поточна версія гарантовано підтримує вибір:

- самої папки гри (наприклад, `Black Desert Online`)
- її безпосередньої батьківської папки (наприклад, `Pearlabyss`)

Якщо в батьківській папці єдиний підкаталог з грою, застосунок знайде його автоматично.

## Вибір режиму локалізації

![Вибір режиму локалізації](docs/img/select-localization-mode.png)

Застосунок отримує список доступних режимів з сервера. Режими можуть змінюватися — конкретний перелік залежить від поточних серверних даних.

- Оберіть одну з доступних карток режиму; вся картка є клікабельною
- Для кожного режиму показано назву, версію, номер патчу та дату релізу
- Встановлений реліз позначено: **✓ Встановлено**
- Клавіші `Tab`, `Space` та `Enter` доступні для навігації й вибору

У списку відображаються режими, для яких сервер наразі надає доступний реліз.

## Встановлення

1. Переконайтеся, що гру знайдено
2. Оберіть потрібний режим локалізації
3. Натисніть **"Встановити"**
4. Дочекайтеся завершення

Застосунок виконає:

- завантаження файлу з перевіркою SHA-256
- створення резервної копії поточного стану
- атомарну заміну файлу локалізації
- перевірку встановленого файлу

Під час операції картки режимів блокуються, а нижня панель показує поточний етап, прогрес і кнопку **"Скасувати"**:

![Встановлення локалізації](docs/img/installation-progress.png)

При успішному встановленні:

> Локалізацію успішно встановлено.

![Успішне встановлення локалізації](docs/img/installation-complete.png)

## Перемикання режимів

![Встановлення іншого режиму](docs/img/switch-localization-mode.png)

Якщо вже встановлено один режим локалізації, можна обрати інший та натиснути **"Встановити"**. Новий режим замінить поточний.

Під час перемикання поточний встановлений режим залишається позначеним, а вибраний режим показує стан операції:

![Перемикання режиму локалізації](docs/img/switch-progress.png)

Після завершення новий режим стає встановленим, а попередній знову доступний для вибору:

![Перемикання режиму завершено](docs/img/switch-complete.png)

Якщо для поточного встановленого режиму доступний новіший реліз, та сама основна кнопка змінює напис на **"Оновити"**. Окремої другої кнопки оновлення немає.

Якщо обраний реліз уже точно встановлено, основна кнопка **"Встановити"** неактивна.

## Оновлення локалізацій

Нові переклади та релізи публікуються на сайті [bdo-ua.com.ua](https://bdo-ua.com.ua/). Після виходу нового патчу гри оновлення зазвичай готується та публікується в четвер — після перевірки й фіксації перекладу.

Застосунок отримує актуальний список із API сайту. Коли для вже встановленого режиму з'являється новий реліз, картка показує **"Доступне оновлення"**, а основна кнопка змінюється на **"Оновити"**:

![Доступне оновлення локалізації](docs/img/localization-update-available.png)

Якщо для поточного патчу ще немає опублікованого релізу перекладу, режим не показується серед доступних для встановлення в лаунчері. Він з'явиться автоматично після того, як API отримає актуальний реліз. Технічно API може повернути сам режим із відсутнім `current`, але застосунок навмисно не показує такий режим як доступний для запуску або встановлення.

Неактуальні або несумісні релізи також не запускаються через кнопку встановлення: застосунок перевіряє доступність і сумісність перед операцією.

Під час відновлення нижня панель показує етап операції, прогрес і доступну кнопку скасування:

![Відновлення оригінального файлу](docs/img/restore-progress.png)

Після успішного завершення застосунок підтверджує відновлення оригінальних файлів:

![Оригінальні файли відновлено](docs/img/restore-complete.png)

## Стан

Блок стану показує поточну інформацію:

- **Стан локалізації** — фактичний стан встановленого файлу та поточного вибору:
  - ✓ Обраний режим уже встановлено
  - Обрано інший режим локалізації
  - Доступне оновлення локалізації
  - Локалізацію не встановлено
- **Встановлено зараз** — що фізично встановлено (режим, версія, дата)
- **Обрано для встановлення** — який режим буде встановлено після натискання основної кнопки
